# SageSync — Claude Code instructions

Node.js service that **syncs Sage300 inventory → Fracttal**. One-way, on-premise (Windows Server), license-gated, deployed as a Windows Service.

> If this is the first thing you read in a session, also open [`HANDOFF.md`](./HANDOFF.md) and skim section 1-5. Real architecture detail lives in [`ARCHITECTURE.md`](./ARCHITECTURE.md). Historical context and gotchas in [`docs/MEMORY.md`](./docs/MEMORY.md).

## Stack

- Node.js 18, Express 4.18, axios 1.6, node-cron 3
- mssql 10 (Sage300 read-only), winston 3 (logger singleton)
- Jest 29 + supertest 6
- node-windows installed but production uses **Servy** for service management
- javascript-obfuscator for the dist build (CI-only)

## Architecture in 4 lines

`src/main.js` boots Express + cron (license gate first). Each tick reads Sage300 via `SageService`, maps locations to Fracttal warehouses via `config.json`, then for every item picks one of three cases (exists+in warehouse / exists not in warehouse / new) and calls `FracttalClient` with the canonical endpoints (`/inventories/` + `/inventories_adjustment/`). `LicenseValidator` runs in-band: startup gate exits on failure, periodic re-validation in cron, synchronous cache feeds `requireLicense` middleware and `/api/system/license`.

## Critical files

| Path | Purpose |
|------|---------|
| `src/main.js` | Server + cron entry point. License gate goes BEFORE express.static. |
| `src/app.js` | `syncInventory()` — the 3-case sync logic. Also has its own headless cron entry. |
| `src/sync.js` | One-shot CLI wrapper. `npm run sync`. |
| `src/services/LicenseValidator.js` | HMAC + freshness + 3-state cache + 24h TTL. DO NOT modify lightly. |
| `src/services/fracttalClient.js` | All Fracttal API calls. Canonical methods: `createInventoryWithWarehouse`, `associateItemToWarehouse`, `adjustInventoryStock`. Legacy `createInventoryItem`/`updateWarehouseItem` are deprecated. |
| `src/services/sageService.js` | SQL queries against `COPDAT.dbo.ICILOC ⋈ ICITEM`. Read-only. |
| `src/middleware/requireLicense.js` | Synchronous gate, returns 503. Exemption for `/api/system/license` is in `main.js` not here. |
| `src/utils/validateEnv.js` | Boot-time env var validation. Lists missing vars and exits. |
| `config.json` | Sage location → Fracttal warehouse mapping. Generated by `scripts/setup-automap.js`. |
| `scripts/obfuscate.js` | Dist build. Triggered by CI, not by hand. |
| `scripts/install-service.ps1` | Windows Service installer via Servy. |

## Conventions (read this before editing)

- **Language is mixed by file.** Older files (`app.js`, `sageService.js`, `fracttalClient.js`, `maintenance.js`, `configManager.js`) are Spanish — variables, comments, log messages. Newer files ported or written for v1.1 (`LicenseValidator.js`, `requireLicense.js`, `validateEnv.js`, `license.js`) are English. **Keep the file's language when you edit it; do not mix within one file.** Logs to users are in Spanish across the board.
- **Logger is a Winston singleton.** `require('../config/logger')`. Never `console.log` for production paths. Levels: `info` normal, `warn` recoverable, `error` real failure, `debug` only when `LOG_LEVEL=debug`.
- **Error pattern in services:** try/catch around the network call → `logger.error('Spanish message:', err.response?.data || err.message)` → `throw error`. Never swallow.
- **Per-item errors don't abort the loop.** `src/app.js` `for` loop has an outer catch that increments `errors` and `continue`s. Each item is independent.
- **Async handlers** in controllers use `asyncHandler` from `src/middleware/errorHandler.js` so the global handler catches rejections.
- **License gate ordering matters in `main.js`:** `validateEnv` → `validateLicense({startup:true})` → `express.json` → `requireLicense` wrapper (exempts `/api/system/license`) → `express.static` → routes → `errorHandler`. Don't reorder.
- **Token persistence** lives in `.fracttal-token` (gitignored). Created/updated by `FracttalClient.authenticate()`/`refreshAccessToken()`.

## State outside the repo

Files SageSync writes/reads on disk:

- `.fracttal-token` — OAuth2 access + refresh + expires_at. Auto-regenerated. Delete to force re-auth.
- `logs/sagesync.log` + `logs/error.log` — Winston, 10MB × 5 rotation.
- `logs/servy-stdout.log` + `logs/servy-stderr.log` — In production only, Servy-captured stdio.
- `config.json` — Sage→Fracttal mapping. Generated by `setup-automap.js`.
- `.env` — Secrets. Never commit. Required by `validateEnv` at boot.

## Don't touch without thinking twice

- **`src/services/LicenseValidator.js`** — HMAC, freshness, TTL, DNS. Any change risks breaking enforcement. If you must change, re-run `tests/services/LicenseValidator.test.js` and read [`docs/MEMORY.md`](./docs/MEMORY.md) section 1.1 and 1.6 first.
- **`scripts/obfuscate.js`** — Production distribution depends on it. Test with `--dry-run` style behavior (no `--push`) before changing options.
- **The two-step Case C in `src/app.js`** — `createInventoryWithWarehouse` followed by `adjustInventoryStock`. They are not optional. See `docs/MEMORY.md` section 2.2.
- **`requireLicense` exemption logic in `main.js`** — keep the middleware single-responsibility.
- **`.github/workflows/obfuscate-deploy.yml`** — CI pipeline that pushes to `SageSync-dist`. Changes here need the `OBFUSCATED_REPO_TOKEN` secret to keep working.

## Out of scope

- **Sister projects in `../sageconnect/` and `../sageconnect-license/`.** Don't read or modify. `sageconnect-license` is the license server SageSync talks to; if you need to change it, that's a separate engagement.
- **Real-time sync** — explicitly out of scope per `.planning/PROJECT.md`. Cron-based is the chosen approach.
- **Multi-tenant in one SageSync instance** — each client gets its own deployment.
