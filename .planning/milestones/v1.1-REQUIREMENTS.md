# Milestone v1.1 — Requirements (Archived)

**Archived:** 2026-05-14
**Defined:** 2026-04-07
**Shipped:** 2026-04-08
**Core Value at time of milestone:** Sage300 inventory data stays in sync with Fracttal automatically.

## License Validation

- [x] **LIC-01**: App validates license against remote server on startup (3 retries with exponential backoff). _Outcome: validated — `LicenseValidator.validate()` retries with backoff; failure after 3 attempts triggers `process.exit(1)` via `main.js`/`app.js`/`sync.js`._
- [x] **LIC-02**: App validates license periodically on each cron sync cycle. _Outcome: validated — every cron tick calls `validateLicense({ startup: false })` before invoking `syncInventory`._
- [x] **LIC-03**: License response verified via HMAC-SHA256 signature with shared secret. _Outcome: validated — `LicenseValidator` rejects any response whose signature does not match the locally computed HMAC over the canonical payload._
- [x] **LIC-04**: Timestamp freshness check rejects responses older than 5 minutes. _Outcome: validated — 5-minute freshness window enforced; older payloads transition to `INVALID`._

## License Enforcement

- [x] **ENF-01**: All API routes except `/api/system/license` return 503 when license is invalid. _Outcome: validated — `requireLicense` middleware mounted before all routes; only `/api/system/license` is exempted (exemption logic in `main.js` wrapper)._
- [x] **ENF-02**: Cron sync cycles are skipped when license is invalid. _Outcome: validated — cron callback checks license state and skips `syncInventory` with a `warn` log when not `VALID`._
- [x] **ENF-03**: App exits with code 1 if license validation fails at startup after retries. _Outcome: validated — startup gate in `main.js`, `app.js`, and `sync.js` all call `process.exit(1)`._
- [x] **ENF-04**: Three-state cache model (VALID/INVALID/ERROR) with 24h ERROR→INVALID TTL. _Outcome: validated — `LicenseValidator` exposes `getStatus()` with the three states; `ERROR` state transitions to `INVALID` after 24h of no successful check._

## License Status

- [x] **STS-01**: `GET /api/system/license` endpoint returns current license state (always accessible). _Outcome: validated — endpoint returns `{ state, active, expiresAt, lastChecked, lastSuccessfulCheck, hmacConfigured }`. Exempted from `requireLicense` so it returns even when license is invalid._
- [x] **STS-02**: Frontend dashboard shows license status banner when invalid/expiring. _Outcome: validated — sticky red banner on `INVALID`/`ERROR`, full-page blocking overlay on `INVALID`/`ERROR`, yellow/red expiry badge for `VALID` state within 30/7 days, 60s polling._

## Configuration

- [x] **CFG-01**: License configured via environment variables (`LICENSE_API_URL`, `HMAC_SECRET`, `SAGESYNC_API_KEY`). _Outcome: validated — `src/config/license.js` reads the three env vars; `src/utils/validateEnv.js` fails fast if any are missing._
- [x] **CFG-02**: DNS bypass detection logs warning when license server resolves to private/loopback IP. _Outcome: validated — non-blocking warning logged when hostname resolves to RFC1918 or loopback ranges._
