  <action>
Modify all three entry points to gate on license validation. Per user decision: "Make sure that NOTHING works without that key" and "ALL three entry points must be gated."

There are TWO levels of license gating:
1. **Startup gate** -- `await validateLicense({ startup: true })` before server/cron starts (LIC-01, ENF-03)
2. **Periodic gate** -- `await validateLicense()` (no startup flag) at the top of each cron callback, so every sync cycle re-validates the license (LIC-02)

The startup gate uses `{ startup: true }` which triggers retry+exit logic. The periodic gate uses no arguments, which returns the result without calling process.exit -- if the license has become invalid, the cron callback should check `isValid()` and skip the sync.

**src/main.js** -- Wrap entire startup in async function:

1. Add imports at very top (before any service instantiation):
   ```javascript
   const { validateEnv } = require('./utils/validateEnv');
   const { validate: validateLicense, isValid } = require('./services/LicenseValidator');
   ```

2. Call `validateEnv()` synchronously at module scope (before any `new SageService()`, `new FracttalClient()`, etc.)

3. Wrap everything from `const app = express()` through `app.listen()` and cron scheduling inside a `async function startServer()`:
   ```javascript
   async function startServer() {
       await validateLicense({ startup: true });
       // ... all existing Express setup, middleware, routes ...

       // Cron scheduling with periodic license re-validation (LIC-02):
       cron.schedule(config.syncSchedule, async () => {
           try {
               await validateLicense(); // Re-validate license on each cron cycle
               if (!isValid()) {
                   logger.error('License invalid — skipping scheduled sync');
                   return;
               }
               if (!syncStateManager.isInProgress()) {
                   console.log('\n🔄 Ejecutando sincronización programada...');
                   await runSyncWithTracking(syncStateManager);
               } else {
                   logger.warn('Sincronización programada saltada - ya hay una en progreso');
               }
           } catch (error) {
               logger.error('Error en sincronización programada:', error);
           }
       });

       // ... app.listen, syncOnStartup, etc. ...
   }
   startServer().catch((err) => {
       const logger = require('./config/logger');
       logger.error('Fatal startup error:', err);
       process.exit(1);
   });
   ```
