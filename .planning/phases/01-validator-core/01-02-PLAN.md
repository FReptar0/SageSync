3. CRITICAL: The `cron.schedule()` call on line 174 runs at module scope. This means when `sync.js` does `require('./app')`, the cron scheduling executes immediately. Wrap the cron scheduling and `if (require.main === module)` block in an async start function:
   ```javascript

       await validateLicense({ startup: true });
       cron.schedule(process.env.SYNC_CRON_SCHEDULE || '0 2 * * *', syncInventory);
       if (require.main === module) {
           syncInventory();
       }
   }
   start().catch((err) => {
       logger.error('Fatal startup error:', err);
       process.exit(1);
   });
   ```

This is actually fine -- the second call uses the cached VALID state and returns immediately. But if the first fails (exits), sync.js never runs. This is the desired behavior.
