4. If any missing: `console.error()` a formatted list with group labels, then `process.exit(1)`
5. Export `{ validateEnv }`

Error format example:
```
[ENV ERROR] Missing required environment variables:
  - LICENSE_API_URL (license)
  - DB_HOST (database)
```
